# ImageAutoInserter

Automatically insert images into Excel spreadsheets by product codes

按商品编码自动把对应图片批量插入 Excel 表格。选好图片和 Excel，点一下「开始处理」即可。

## 功能特点

- **自动匹配插入** — 按 Excel 中的商品编码自动找到对应图片，批量插入到 Picture 列
- **图片来源灵活** — 文件夹、ZIP、RAR、7Z 直接选；一个文件夹里放了多个压缩包也能一次全部处理，散落图片一并合并，重复图片先到先得
- **多工作表同时处理** — 一个 Excel 里有多个含「商品编码」列的工作表时，全部同时处理，各自识别表头
- **大批量不卡死** — 并行加载图片 + 智能调度（自动检测 CPU 与存储类型计算最优并行度）；图片以文件路径方式传入，保存时按需读取，内存占用与图片数量无关
- **常见格式全支持** — 图片支持 jpg / jpeg / png / gif / bmp / webp；商品编码列是 VLOOKUP 等公式也能正确识别
- **处理完一键查看** — 实时进度显示，完成后直接打开结果文件检查，未匹配到图片的编码自动标黄提醒
- **安全省心** — U 盘、移动硬盘上的源文件先临时处理、完成后引导另存，不怕中途拔盘丢文件；压缩包带路径安全与解压炸弹防护
- **开箱即用** — 应用自带 Python 运行环境，安装后无需安装任何东西
- **应用内更新** — 仅在主动点击时检查新版本，发现更新后直接在应用内下载安装，无需跳转浏览器
- **跨平台** — macOS（Apple Silicon）与 Windows（x64）

## 使用说明

1. 选择图片来源（文件夹、ZIP、RAR 或 7Z 文件，或包含多个压缩包的文件夹）
2. 选择 Excel 文件
3. 点击「开始处理」
4. 等待处理完成
5. 点击「打开文件」在 WPS / Excel 中查看结果，检查无误后自行另存为

首次使用会弹出操作引导，跟着提示走即可；之后可随时点右上角的帮助按钮重新打开。

## 系统要求

- macOS 11+（Apple Silicon）/ Windows 10+（x64）

## 架构说明

### 处理流程

```
图片来源（文件夹 / ZIP / RAR / 7Z，支持多压缩包混放）
        │  Node.js 统一提取到临时目录（重复图片先到先得）
        ▼
Python 引擎：并行加载图片 → 解析 Excel（表头 / 编码列 / 多工作表）
        → 逐行匹配并嵌入图片 → 高亮未匹配行 → 原子保存
        ▼
完成后一键打开结果文件
```

| 阶段 | 范围 | 说明 |
|------|------|------|
| 启动进程 | 0-2% | 初始化运行时 + 验证文件路径 |
| 加载图片 | 2-14% | 扫描图片来源，并行加载图片 |
| 解析Excel | 15-25% | 打开 Excel + 查找商品编码列 + 解析数据行 |
| 处理数据 | 25-72% | 逐行匹配图片 + 嵌入到 Excel 单元格 |
| 高亮未匹配行 | 72% | 高亮未匹配到图片的商品编码单元格 |
| 保存文件 | 92-100% | 保存 Excel 文件（原子替换模式） |

### 压缩包提取与安全

所有压缩包（ZIP / RAR / 7Z）统一由 Node.js 端提取到临时目录，Python 只扫描已提取的文件夹，不再直接处理压缩包。ZIP / 7Z 由 7zip-min 处理，RAR 由 node-unrar-js（WASM）处理，均无需外部工具。

安全措施：

- 压缩包条目路径验证，防止路径遍历攻击
- 解压炸弹防护（限制条目数、单文件大小、总解压大小）
- 文件名安全校验，拒绝危险字符
- 临时文件会话管理，处理完成或出错时自动清理
